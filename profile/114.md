## Step 23 - Configure OpenSSH Default Shell

Problem:

SSH sessions started in Command Prompt.

```text
scott@DELL C:\Users\Scott>
```

Solution:

```powershell
New-Item "HKLM:\SOFTWARE\OpenSSH" -Force

New-ItemProperty `
-Path "HKLM:\SOFTWARE\OpenSSH" `
-Name DefaultShell `
-Value "C:\Windows\System32\WindowsPowerShell\v1.0\powershell.exe" `
-PropertyType String `
-Force
```

Expected result after reconnecting:

```text
┌──(scott💀dell)-[~]
└─#
```
